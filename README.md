# Bajaj Training Session

A collection of Java implementations for classic Data Structures and Algorithms (DSA) problems.

## Overview
This repository contains 60+ standalone Java files covering a range of DSA concepts. All source files are located in the root directory.

## Topics Covered
- Arrays and Strings
- Linked Lists
- Trees and Graphs
- Dynamic Programming
- Stacks and Queues

## Prerequisites
- Java Development Kit (JDK) 8 or later

## How to Run
Compile and run any Java file directly from the root directory:

```bash
javac <ClassName>.java
java <ClassName>
```

Example:

```bash
javac TwoSum.java
java TwoSum
```
